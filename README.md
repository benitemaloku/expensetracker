# Expense-Tracker

Expense Tracker is a web application designed to assist individuals in managing their personal finances.
It offers a simple way to record, visualize, download and delete income and expenses, with a modern and responsive interface.


## **Features**

**User Authentication:**
   - Login page
   - Register page
   - Edit profile
   - Logout

**Home Pages:**
  - **Dashboard**
    - Displays graphs for income and expenses.
  - **Income Page**
    - Add income
    - Delete income
    - Download data
  - **Expense Page**
    - Add expenses
    - Delete expenses
    - Download data

## Visualization
Dynamic graphics on the Dashboard to compare income and expenses.
Data can be downloaded for further analysis.

## Technologies used
- **Frontend** : [Vite](https://vitejs.dev/), [React.js](https://react.dev/), [Tailwind CSS](https://tailwindcss.com/)
- **Backend**: [Node.js](https://nodejs.org/)
- **Database**: [MongoDB](https://www.mongodb.com/)
